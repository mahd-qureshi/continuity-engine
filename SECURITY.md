# Security and privacy

Version 0.1 is a static local application. It has no backend, accounts,
cookies, storage, analytics, third-party scripts, or network calls.

Do not include private conversations, proprietary prompts, credentials, or
unlicensed story material in issues, fixtures, or pull requests.

If a security problem is discovered, report it privately through GitHub's
repository security-advisory flow rather than opening a public issue.
