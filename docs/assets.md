# Artwork

`assets/mara-platform.jpg` is the portrait used in the demo. It was generated
for this project with the built-in OpenAI ImageGen tool and depicts Mara, a
fictional character, waiting at a railway station.

The generated PNG was converted to a compressed JPEG for delivery. The HTML
uses the JPEG for the character portrait and social preview. The Pages build
excludes the intermediate `mara-platform.png` from its public artifact.

The interface logo is an inline SVG. No external image or font service is
needed to render the story.

## Generation brief

Portrait of Mara, 24, with a short dark bob and muted olive coat, sitting on a
railway platform bench with an ochre bag and considering a message on her phone.
Graphite linework and flat gouache on warm ivory paper; charcoal, olive, and
ochre palette. Quiet book-cover composition, visible pencil texture, generous
negative space, no lettering or logos. Generated with the built-in ImageGen tool.

`docs/preview.jpg` is a screenshot of the actual desktop interface.
